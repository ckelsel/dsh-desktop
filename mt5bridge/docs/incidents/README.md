## 新增条目的约定

- 文件名 `YYYY-MM-DD-<slug>.md`，日期用**定位修复日**（首发日在正文里写）。
- 必含五节：症状 / 走过的弯路（无效动作也要记，防重蹈）/ 根因（附实验证据）/ 修复（附提交号）/ 再遇到时的排查姿势。
- 根因没钉死之前不写"已修复"；只写"疑似 + 待验证"。
